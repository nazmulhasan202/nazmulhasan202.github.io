Deployed app2025

Machine failure prediction, end to end

A Random Forest classifier on the AI4I 2020 predictive maintenance dataset, wrapped in a deployed Streamlit application that predicts failure from air temperature, process temperature and rotational speed.

Why I built the deployment half

A notebook that reports an F1 score proves very little about whether the work would survive in production. I built this one specifically to practice the parts that usually get skipped: packaging the model, handling input the user actually supplies, and keeping the thing running where somebody other than me can reach it.

  • Random Forest
  • Streamlit
  • Predictive maintenance
