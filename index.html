WDWestern DigitalSummer 2026

Supply allocation optimization engine

Hard drive supply was allocated first come, first served. I replaced that with a max-min fairness linear program in FICO Xpress that maximizes the minimum weeks of supply across customers within each supply pool.

  • ~12,000allocation decisions per run
  • 400+ / 200+products / customers
  • < 1 minsolve time
  • 7live Oracle sources

Presented the completed engine to senior leadership, including the ITLT team. It is in user testing now.

How it was built

The model was the smaller half. Underneath it sits an end-to-end Python and pandas pipeline across seven live Oracle sources: supply, statistical forecast, point-of-sale sell-through, channel inventory, confirmed backlog and pegged supply. I diagnosed and repaired a 0% key-match defect between two of those sources, built a four-level hierarchical imputation for missing sell-through, and corrected a fiscal calendar timing mismatch that had been quietly shifting results by a week.

Where the LP ran out. The base formulation could not resolve week-level shortfalls, so I designed a separate two-pass rollover algorithm: a forward drain followed by a LIFO surplus carry.

Architecture. Two independently deployable services, a Streamlit pipeline and interface tier and an isolated FICO Xpress solver tier, communicating through a shared handoff database. Scenario storage is immutable, so any run can be replayed for audit.

What planners actually see. A Streamlit and Plotly dashboard with planning horizon controls, business filters, customer-group and location-level targets, and Excel and CSV export. I wrote the full technical handover document before leaving.

Worked across sales operations, strategy and business applications teams. I also directed Devin, an AI coding agent, for implementation-heavy tasks while keeping ownership of the algorithm and the architecture.

QCIISE QCRE Data Challenge20261st place

Defect detection that outperformed deep learning, at 0.58 s per image on a CPU

I led a three-person team to first place. The task was detecting perforation defects in packaging images. Rather than training a deep network, we tied each defect type to a measurable physical or geometric feature and detected it through morphological image processing.

  • 1.9913 / 2.0competition score
  • > 99%accuracy and F1
  • 0.58 sper image, CPU only
  • 23 teams29 institutions, 4 countries

The result is interpretable, needs no GPU, and is fast enough for high-throughput inspection. It beat the deep learning entries.

Why we did not use deep learning

A competition leaderboard rewards accuracy, but a factory rewards something else: a quality engineer has to be able to say why a part was rejected, and the line will not wait for a GPU. Those two constraints pointed away from a learned feature extractor.

So we inverted the usual approach. For each defect class we asked what physically distinguishes it, expressed that as a geometric or morphological property, and built a detector for that property directly. The pipeline carries no trained weights, which means nothing drifts, nothing needs retraining on a new batch, and every decision traces back to a measurable quantity.

Dataset provided by Five Star Management Group. Team: Mohamed Ibrahim and Ryan Mowlai, University of Arizona.

RORoche2026

MILP staff task distribution tool

Coordinators were matching qualifications, respecting staffing limits and handling operational constraints by hand every morning, across dozens of people and tasks. Workload came out uneven and urgent work kept landing on the same few individuals.

I led the optimization and tool development: two Mixed-Integer Linear Programming models run in sequence, the first maximizing coverage breadth across the team, the second minimizing workload imbalance while balancing urgent assignments. A coordinator uploads an input file and receives recommended assignments through an interactive dashboard within minutes.

Designing for people who will not open a terminal

The users are operational coordinators, not engineers. A tool they cannot run is worth nothing regardless of how good the formulation is, so usability drove most of the design decisions: a single launcher, a file picker instead of a command line argument, an HTML dashboard in the browser they already have open, and export options for the formats they already pass around.

I also wrote a detailed user guide so a new coordinator can be onboarded without hands-on training from us. The tool is moving into real operational use rather than sitting in a repository.

Supervised by Dr. S. J. Youn at the University of Arizona, coordinated with the industry sponsor. Teammates Sandhya Rangaswamy, Yashwin Krishnakanth S, Gaurv Singh and Samarie Tavenner led other parts of the engagement.

UAPhD dissertation2021 - present

PhD dissertation: in-situ quality monitoring for metal 3D printing

My dissertation is quality assurance in laser powder bed fusion: using process monitoring data and machine learning to catch defects in aerospace alloys such as Inconel 718 and Haynes 282, while the part is still being built rather than after it fails inspection.

  • 0.90Dice score, RAMPSeg segmentation
  • 11x / 75xfaster than SAM / CLIPSeg
  • 0.865F1, overheating detection
  • +66.7%data utility from sensor synchronization
The four threads of the dissertation

Segmentation. RAMPSeg is a calibration-free melt pool segmentation method reaching a Dice score near 0.90 with a standard deviation of 0.04, and it outperforms thresholding, Otsu, Meta's SAM and OpenAI's CLIPSeg while running an order of magnitude faster. Published in the Journal of Intelligent Manufacturing.

Anomaly detection. Ensemble models over real-time photodiode data detect overheating layer by layer at F1 = 0.865, a 9.66% improvement over the prior state of the art. Porosity models reach F1 = 0.879.

Knowledge representation. An ontological framework that structures defect and causal-factor knowledge into a graph, so process planning decisions trace back to evidence rather than to institutional memory. Finalist for the IISE Best Student Paper Award in 2023.

Physics-guided modeling. Correlating thermal process history to solidification microstructure with R squared between 0.90 and 0.95, cutting roughly 1.5 hours of analysis per case.

Carried out with NASA Glenn Research Center, Lockheed Martin, CompuTherm and ARCTOS. I have presented this work at NAMRC, IISE and INFORMS, and co-led a Fulbright workshop on applied AI for smart industrial systems in metal additive manufacturing.
